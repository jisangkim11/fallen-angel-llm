# LLM 기반 Fallen Angel 예측 및 이벤트 드리븐 전략

LLM이 기업 공시(10-K, 8-K)를 신용평가사 기준으로 점수화하고, 이를 신용등급·채권 스프레드 같은 시장 데이터와 결합해 **투자등급(BBB) 채권이 12개월 안에 투기등급으로 떨어질 확률**을 예측합니다. 그리고 그 결과로 **강등 이후 강제 매도로 눌린 채권을 골라 사는 이벤트 드리븐 전략**을 설계했습니다.

> 한양대학교 금융공학회 HYFE 파생 & 퀀트 프로젝트 (2026-2) · 발표자료: [`docs/presentation.pdf`](docs/presentation.pdf)

---

## 배경
- 투자등급(BBB-) 채권이 투기등급(BB+ 이하)으로 떨어지면(**Fallen Angel**), 투자등급만 담을 수 있는 펀드·보험사·연기금이 한꺼번에 팔아야 합니다.
- 이 강제 매도로 강등 직후 가격이 과도하게 떨어졌다가, 이후 약 12개월에 걸쳐 회복합니다.
- 이 **이벤트 전후의 가격 왜곡**을 이용하는 전략을 만들기 위해, 먼저 강등을 예측하는 모형이 필요했습니다.

## 구조

```
 ① LLM 채점                 ② 강등 확률 예측                ③ 이벤트 드리븐 전략
 10-K / 8-K 공시      →     LLM 점수 + 신용등급 + 스프레드  →  강등 월 말, 눌린 정도 +
 S&P 방법론 4개 축 채점      로지스틱 회귀 (12개월 내 강등)      LLM 사업위험으로 선별 매수
 (사업·재무·유동성·재무정책)
```

### ① LLM 공시 채점
- 모델: Google **Gemma 4** (학습 없이 프롬프트와 기준표로 채점)
- 입력: 10-K의 사업·위험요인·MD&A 중 신용 관련 단락, 8-K의 인수·차입·구조조정·자산손상 공시
- 기준표: S&P 기업 평가방법론의 4개 축을 0·5·10점 기준 문장으로 정리
- 출력: JSON 형식 점수 → 토큰 확률 가중평균 기대점수 → 매월 BBB 기업 내 백분위
- 누출 통제: 연도 가림(2019 → [FY0]), LLM 기억 테스트(156건 중 1건 제외), 온도 0

### ② 강등 확률 예측
- L2 로지스틱 회귀, 변수를 한 층씩 쌓는 모형 사다리로 비교
  - M1 신용평가사 → M2 +스프레드 → M3 +재무비율 → M4 +LLM, 최종 복합 모델 = M2 + LLM
- 미래 정보 차단: 예측 시점보다 최소 12개월 앞선(정답이 확정된) 데이터로만 학습, 공시는 제출 달부터 반영

### ③ 이벤트 드리븐 전략: 강등 후 선별 매수
| 항목 | 규칙 |
|---|---|
| 이벤트 | S&P 등급 BBB- 이상 → BB+ 이하 강등 |
| 진입 | 강등된 달 말 (투자등급 지수 편출 = 강제 매도 종료 시점) |
| 선별 | 강등 직전 초과 스프레드 상위 2/3 (많이 눌림) + LLM 사업위험 하위 80% (사업은 버틸 만함) |
| 비중 | 눌린 정도에 비례, 종목당 최대 10% |
| 청산 | 최대 12개월 · 추가 강등 시 손절 · 투자등급 복귀 시 익절 |
| 비용 | 진입·청산 각 25bp |

## 주요 결과 (2016~2024)

**예측: S&P 경고가 없는 구간의 경보 정확도 (PR-AUC)**
| 모델 | PR-AUC | 비고 |
|---|---|---|
| 무작위 | 0.010 | |
| M1 신용평가사 | 0.020 | |
| M2 + 스프레드 | 0.067 | |
| **복합 모델 (M2 + LLM)** | **0.079** | 스프레드 대비 +18% |

- 스프레드가 없는 채권(관측치의 34%)에서 LLM 추가 시 PR-AUC 0.026 → 0.040 (+50%, p = 0.012)
- 다른 신호를 통제해도 LLM 사업위험 1 표준편차 ↑ → 강등 Odds 1.73배

**전략: 강등 후 선별 매수**
| 전략 | 연 수익 | 샤프 | 2020년 제외 샤프 |
|---|---|---|---|
| BBB 지수 | 2.34% | 0.40 | 0.88 |
| 폴른 엔젤 전부 매수 | 6.65% | 0.56 | 0.75 |
| **선별 매수** | **8.67%** | **0.62** | **0.92** |

## 한계
- 사전에 정한 주 검정(M4 vs M3)은 p = 0.17로 기준 미달이며, 최종 복합 모델과 일부 분석은 결과 확인 후 추가했습니다 (발표자료 부록에 전부 공개).
- 폴른 엔젤 156건, 시험 기간 9년으로 표본이 작고, 전략은 평균 4종목에 집중됩니다.
